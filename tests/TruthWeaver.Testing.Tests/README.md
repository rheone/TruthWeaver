# TruthWeaver.Testing.Tests

Tests for [TruthWeaver.Testing](../../src/TruthWeaver.Testing/README.md).

## Purpose

This project checks the test helpers: fake predicates, decision assertions, rule test files and the rule fuzzer.

## Depends on

- [TruthWeaver.Abstractions](../../src/TruthWeaver.Abstractions/README.md) for the shared value types.
- [TruthWeaver](../../src/TruthWeaver/README.md) for the compiler and the evaluator.
- [TruthWeaver.Testing](../../src/TruthWeaver.Testing/README.md) for the code under test.
