# TruthWeaver.Generators.Tests

Tests for [TruthWeaver.Generators](../../src/TruthWeaver.Generators/README.md).

## Purpose

This project checks the predicate source generator.

It runs the generator with Roslyn and checks the generated output, the diagnostics and the generated Register code.

## Depends on

- [TruthWeaver.Abstractions](../../src/TruthWeaver.Abstractions/README.md) for the shared value types.
- [TruthWeaver](../../src/TruthWeaver/README.md) for the compiler and the evaluator.
- [TruthWeaver.Generators](../../src/TruthWeaver.Generators/README.md) for the generator under test.
