# TruthWeaver.AspNetCore.Tests

Tests for [TruthWeaver.AspNetCore](../../src/TruthWeaver.AspNetCore/README.md).

## Purpose

This project checks rule requirements, the authorization handler and the problem-details response against an in-memory ASP.NET Core host.

## Depends on

- [TruthWeaver.Abstractions](../../src/TruthWeaver.Abstractions/README.md) for the shared value types.
- [TruthWeaver](../../src/TruthWeaver/README.md) for the compiler and the evaluator.
- [TruthWeaver.AspNetCore](../../src/TruthWeaver.AspNetCore/README.md) for the code under test.
- [TruthWeaver.Testing](../../src/TruthWeaver.Testing/README.md) for fake predicates.
