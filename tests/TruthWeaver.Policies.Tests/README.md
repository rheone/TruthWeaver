# TruthWeaver.Policies.Tests

Tests for [TruthWeaver.Policies](../../src/TruthWeaver.Policies/README.md).

## Purpose

This project checks policy sets: the three combining algorithms, targets, priorities and the handling of Unknown.

## Depends on

- [TruthWeaver.Abstractions](../../src/TruthWeaver.Abstractions/README.md) for the shared value types.
- [TruthWeaver](../../src/TruthWeaver/README.md) for the compiler and the evaluator.
- [TruthWeaver.Policies](../../src/TruthWeaver.Policies/README.md) for the code under test.
- [TruthWeaver.Testing](../../src/TruthWeaver.Testing/README.md) for fake predicates.
