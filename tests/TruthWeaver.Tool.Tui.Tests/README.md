# TruthWeaver.Tool.Tui.Tests

Tests for [TruthWeaver.Tool.Tui](../../src/TruthWeaver.Tool.Tui/README.md).

## Purpose

This project checks the terminal user interface.

## Folders

The test files follow the folders of [TruthWeaver.Tool.Tui](../../src/TruthWeaver.Tool.Tui/README.md). Each test file is
in the folder of the type it tests, with the namespace `TruthWeaver.Tool.Tui.Tests.<Folder>`. The tests that drive the whole
workbench are in `Workbench`. The shared helpers are in `TestSupport`.

## Depends on

- [TruthWeaver.Abstractions](../../src/TruthWeaver.Abstractions/README.md) for the shared value types.
- [TruthWeaver](../../src/TruthWeaver/README.md) for the compiler and the evaluator.
- [TruthWeaver.Tool.Core](../../src/TruthWeaver.Tool.Core/README.md) for the shared tool code.
- [TruthWeaver.Tool.Tui](../../src/TruthWeaver.Tool.Tui/README.md) for the code under test.
