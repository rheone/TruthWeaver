# TruthWeaver.Yaml.Tests

Tests for [TruthWeaver.Yaml](../../src/TruthWeaver.Yaml/README.md).

## Purpose

This project checks YAML rule trees and the YAML data source.

## Depends on

- [TruthWeaver.Abstractions](../../src/TruthWeaver.Abstractions/README.md) for the shared value types.
- [TruthWeaver](../../src/TruthWeaver/README.md) for the compiler and the evaluator.
- [TruthWeaver.Yaml](../../src/TruthWeaver.Yaml/README.md) for the code under test.
- [TruthWeaver.DataSources.Json](../../src/TruthWeaver.DataSources.Json/README.md) for the JSONPath engine that the YAML data source shares.
