**Category:** bug
**Summary:** `RuleBuilder` accepts a `double` argument value of `NaN` or `Infinity` without complaint, then `Compile` throws `ArgumentException` from the JSON writer instead of returning the documented diagnostic.

**Current behavior:** `RuleBuilder`'s value validation treats every `double` as a supported argument type, with no check for non-finite values. `Compile` eventually serializes the builder to JSON internally, and the JSON writer rejects `NaN`/`Infinity`, throwing `ArgumentException` uncaught.

**Desired behavior:** A non-finite `double` argument (`NaN`, `PositiveInfinity`, `NegativeInfinity`) is reported as the documented argument-type-mismatch diagnostic from `Compile`, the same way any other value `RuleBuilder` can't carry through to JSON is reported — never an uncaught exception.

**Key interfaces:**
- `RuleBuilder`'s problem-collection step (the one that already reports other unsupported value shapes) needs to check for non-finite `double` values before `Compile` reaches the JSON-writing step.
