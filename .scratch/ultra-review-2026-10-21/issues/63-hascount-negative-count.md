## Agent Brief

**Category:** bug
**Summary:** The ten `HasCount*` collection predicate factories build their schema with no `ArgumentValidator`, so a negative `count` literal compiles cleanly and silently becomes a constant answer (always `True` or always `False`) for every non-null collection, with no diagnostic — unlike the comparable reversed-bounds mistake on range predicates, which already gets one.

**Current behavior:** A negative `count` argument to any `HasCount*` predicate compiles without error. Because a collection's count is never negative, the term is then a compile-time constant (`HasCountLessThan(count: -1)` always `False`; `HasCountGreaterThanOrEqualTo(count: -1)` always `True`) for every non-null collection — silently turning what was probably meant as a gate into an always-pass or always-fail rule.

**Desired behavior:** A negative literal `count` argument is reported at compile time with a diagnostic (the same family as the reversed-bounds diagnostic range predicates already use). A negative count arriving from a data source at evaluation time is an argument fault, not a silently-constant answer.

## Resolution (2026-11-01)

Per the Decision, a negative count is rejected. The ten `HasCount*` factories now build through a new private `CollectionPredicates.CountPredicate` (in place of the generic `Build`). It sets an `ArgumentValidator` that reports a negative literal `count` as a problem, which the compiler turns into `TRE0026`. At evaluation a negative count (from a data source) throws `ArgumentException` before the selector runs, so the engine records a fault even for a null collection. A count of zero or more is unchanged. Reproduced first: the schema had no validator and `count: -1` evaluated to a constant.

Tests (`CollectionPredicatesTests`, one row per factory): `ArgumentValidator_NegativeLiteralCount_ReturnsOneProblem_Test`, `ArgumentValidator_NonNegativeOrDeferredCount_ReturnsNoProblem_Test` and `Evaluate_NegativeCount_ThrowsArgumentException_Test` (all red before, green after).

Docs: the Arguments table and Edge cases of the ten `docs/strong-k3/predicates/collection-*hascount*.md` pages; `docs/predicates.md` (collection predicates).
