# Functions

Value operations that are not plain connectives. `COALESCE` and the four inspections are external operators, not Strong Kleene connectives. Back to the [reference](../README.md).

| Operation | Summary |
| --- | --- |
| COALESCE | First operand that is not `Unknown` (pending) |
| If | Conditional selection of one of two branches (pending) |
| IsTrue | Inspection: is the operand `True` (pending) |
| IsFalse | Inspection: is the operand `False` (pending) |
| IsUnknown | Inspection: is the operand `Unknown` (pending) |
| IsKnown | Inspection: is the operand `True` or `False` (pending) |
